One-dimensional solute transport in a multi-layered vadose zone with phase partitioning, steady infiltration rate, dual porosity, and first-order reactions (sorption and decay with coefficients that may differ for dissolved and sorbed mass and in mobile and immobile porosity) is solved analytically in the Laplace domain and numerically inverted. The top boundary condition is either specified concentration or a third type with mass exchange with atmospheric air. Four different bottom boundary conditions can b chosen including mass exchange and mixing with groundwater. Steady state and single-layer solutions are included as special cases. The model simulates transport from initial concentration distribution, from the top boundary, and from the water table. The output is aqueous, vapor, or total (all phases) concentration or mass flux density (total or vapor phase).

Example input/output files are in Test1.zip.

Enter "e" after starting the executable to write and example input file with explanation of variables.

T1DL uses a single input file that defines properties of all layers, top and bottom boundary conditions, and specifies type of output (e.g. aqueous or vapor concentration, mass flux, concentration-depth profile, concentration-time series, mass flux profile, etc.).
Output is echo file that repeats all input instructions and result file with the chosen output.

Only forward execution is available at this time.

This is an on-going project and additional model capabilities will be added.
